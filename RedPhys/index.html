An extensible platform

Configure the test. Reuse the evidence.

Adversarial stress testing is the main focus. The same interfaces also support non-adversarial input perturbations and obfuscations without an attack objective.

PhyModels

Physical-world models perform grounded perception, reasoning, prediction, or decision-making about physical scenes.

PhyAgents

Physical-world agents use these models with planning or tool use to carry out grounded tasks.

Scope of the current paper. The study focuses on vision-language PhyModels and tool-using PhyAgents built on vision-language backbones. Evaluation uses scene images, questions, and task-level responses. These terms describe physical-world task roles across model architectures.

Project repository: github.com/loopleap-lab/RedPhys

Functional safety

Failures are wrong actions and judgments in grounded tasks, not harmful text.

Scene-specific targets

A scenario agent builds each target from its scene, the same for every method.

One protocol

One dataset, two metrics and a black-box threat model for attacks and defenses.

Real scenes

Driving, manipulation, grasping, physics, egocentric, diagnostics and scene QA.
