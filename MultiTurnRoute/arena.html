MultiTurnRoute Arena

A router picks which LLM answers each turn of a session. The Arena scores a router on recorded and live sessions for answer quality and cost.

Why the Arena Has Two Tracks

Comparing routers is easy on single questions and hard on multi-turn sessions.

The problemEach reply changes what the user asks next.

A single question can be scored ahead of time. A session branches, so it cannot.

The two tracksStatic ranks routers on one fixed set of models. Dynamic tests your own models and sessions.

Static: keep the recorded session

The history holds the session’s recorded replies. Routers are scored turn by turn, offline.

Dynamic: run the session live

The selected model’s reply shapes the next user query. A judge rates each answer in its dialogue context.

Data and Rules

What stays the same for every submission.

Data3,996 conversations (18,637 turns) from WildChat and LMSYS-Chat-1M, answered by 9 models (granite-3b to mistral-medium-128b). Training turns come with every answer’s grade; test-turn grades stay hidden. The data are not public yet.
JudgeAn LLM grades each answer on a 1–9 score, mapped to 0–1: NVIDIA Nemotron 3.5 Super, same prompt in both tracks.
Simulated userIn the dynamic track, an LLM plays the person chatting: DeepSeek-V4.1-Flash-1017, same set-up for everyone.
CostStatic replay tracks reusable prefixes along each router’s chosen path and uses a fixed price table. In live runs, the router estimates prefixes before selection and the bill uses the selected backend’s reported token usage.
