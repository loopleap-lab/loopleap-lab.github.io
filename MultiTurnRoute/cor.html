Chain-of-Route

Chain-of-Route (CoR) is our routing algorithm in MultiTurnRoute. It predicts response quality from dialogue history and estimates cost from each candidate’s reusable prefix before selecting one model.

HistoryThe Dialogue State Propagator (DSP) combines recent turns with a recurrent summary. A learned gate controls how much history to use for the current query.
